⏱️ 일반 목적 Timer 설명 (TIM2~TIM5)

STM32F20x 시리즈에는 10개의 일반 목적 타이머가 포함되어 있으며, 이 중 TIM2, TIM3, TIM4, TIM5는 고기능 타이머로 다음과 같은 특징이 있습니다:

TIM2, TIM5: 32비트 업/다운 카운터 + 16비트 프리스케일러

TIM3, TIM4: 16비트 업/다운 카운터 + 16비트 프리스케일러

각 타이머는 4개의 독립 채널을 지원하여 입력 캡처, 출력 비교, PWM, One-Pulse 모드 등을 지원함 → 최대 16개의 채널 사용 가능

타이머 간 또는 고급 타이머(TIM1, TIM8)와의 동기화 지원 (Timer Link 기능)

디버그 모드에서도 타이머 정지 지원 가능 (freeze)

PWM 생성 및 엔코더 인터페이스(Quadrature Encoder Mode) 지원

각 타이머는 DMA 요청 생성 가능

📷 참고 이미지:



TIM2~5는 입력 캡처부터 모터 제어까지 다양한 목적에 사용되며, 특히 DMA와 연계하여 고속 신호 측정 및 PWM 제어에 적합합니다.
## DMA Controller (DMA)

STM32 디바이스는 두 개의 범용 듀얼 포트 DMA 컨트롤러(DMA1, DMA2)를 제공하며, 각각 8개의 스트림을 지원합니다. 주요 특징은 다음과 같습니다:

### 📌 주요 기능
- **8 스트림 지원**: 각 DMA 컨트롤러는 8개의 독립된 스트림을 통해 데이터 전송 가능
- **전송 유형 지원**:
  - 메모리 ↔ 메모리
  - 주변장치 ↔ 메모리
  - 메모리 ↔ 주변장치
- **중앙 집중형 FIFO 공유**: APB/AHB 버스에서의 효율적인 데이터 처리
- **버스트 전송 지원**: 고속 데이터 전송을 위한 설계
- **최대 주변장치 대역폭 제공**: AHB/APB 기반 최적화 설계

### 🔁 고급 기능
- **원형 버퍼(Circular Buffer)**:
  - 버퍼 끝에 도달했을 때 자동으로 처음으로 순환
  - 별도 코드 없이 연속 전송 가능
- **더블 버퍼링(Double Buffering)**:
  - 두 개의 버퍼를 자동으로 전환하며 사용
  - 사용자 개입 없이도 안정적인 데이터 전송 보장

### ⚙️ 설정 및 트리거
- **전용 하드웨어 요청 핀**을 통한 DMA 요청 처리
- **소프트웨어 트리거 지원**
- **소스와 목적지의 전송 크기 독립적 설정** 가능
- 모든 구성은 **소프트웨어적으로 설정**됨

---

이 정보는 STM32 DMA 컨트롤러의 기능을 요약한 것으로, 고성능 데이터 전송이 필요한 임베디드 시스템에 매우 적합합니다.

# STM32F20x 주요 하드웨어 기능 정리

## 📦 DMA Controller (DMA)

STM32F20x 시리즈는 두 개의 범용 듀얼 포트 DMA 컨트롤러(DMA1, DMA2)를 제공하며, 각각 8개의 스트림을 지원합니다.

### ✅ 기능 요약
- **지원 전송 방식**: 메모리 ↔ 메모리, 메모리 ↔ 주변장치, 주변장치 ↔ 메모리
- **중앙화된 FIFO 공유 (AHB/APB)**
- **버스트 전송 지원** 및 **최대 주변장치 대역폭 제공**
- **원형 버퍼 (Circular Buffer)** 지원
- **더블 버퍼링 (Double Buffering)**: 자동 전환, 코드 필요 없음
- **각 스트림은 전용 하드웨어 요청 및 소프트웨어 트리거 지원**
- **독립적인 소스/목적지 설정 가능**

### 🔌 DMA 사용 가능 주변장치
- SPI, I²S  
- I²C  
- USART, UART  
- TIMx (범용, 기본, 고급 타이머)  
- DAC  
- SDIO  
- DCMI (카메라 인터페이스)  
- ADC  

---

## 💾 Flexible Static Memory Controller (FSMC)

FSMC는 외부 메모리/디바이스와의 인터페이스를 위한 컨트롤러입니다. STM32F20x 시리즈에 내장되어 있으며, 다음과 같은 모드를 지원합니다:

- **지원 모드**: PC Card / Compact Flash, SRAM, PSRAM, NOR Flash, NAND Flash

### ✅ 기능 요약
- FIFO 쓰기 지원
- 외부 메모리에서 코드 실행 가능 (NAND Flash, PC Card 제외)
- 최대 동작 주파수: **60 MHz**

### 🖥️ LCD 병렬 인터페이스
- Intel 8080 / Motorola 6800 호환
- 다양한 LCD 모드 및 컨트롤러와의 연동 가능
- 비용 효율적인 그래픽 애플리케이션에 적합

---

## ⚡ Nested Vectored Interrupt Controller (NVIC)

NVIC는 STM32F20x에 내장된 인터럽트 컨트롤러로, **최대 81개 인터럽트 채널**과 **16개의 Cortex-M3 인터럽트 라인**을 처리합니다.

### ✅ 주요 특징
- 저지연 인터럽트 처리 (core와 밀접 결합)
- 인터럽트 벡터 주소 직접 전달
- 인터럽트 조기 처리 가능
- 고우선순위 인터럽트의 지연 처리 지원
- **Tail Chaining** 지원 (중첩 인터럽트 최소화)
- 프로세서 상태 자동 저장/복원
- 명령 오버헤드 없이 인터럽트 복귀

> 이 구조는 유연하고 빠른 인터럽트 응답이 필요한 실시간 시스템에 매우 유리합니다.

---
## 🕒 Real-Time Clock (RTC), Backup SRAM, and Backup Registers

STM32F20x 시리즈의 백업 도메인에는 다음이 포함됩니다:
- ✅ **RTC (Real-Time Clock)**
- ✅ **4KB Backup SRAM**
- ✅ **20 Backup Registers**

---

### 🔧 RTC 주요 기능

RTC는 독립적인 BCD 타이머/카운터로 다음과 같은 기능을 제공합니다:

- 시, 분, 초 (12/24시간), 요일, 날짜, 월, 연도를 BCD(Binary-Coded Decimal) 형식으로 저장
- 윤년 포함 자동 날짜 보정 (28, 29, 30, 31일)
- **알람 및 주기적 인터럽트 설정** (Stop 및 Standby 모드에서 자동 웨이크업 지원)
- 32.768kHz 외부 크리스탈 또는 내부 저전력 RC/고속 클럭 기반 동작
  - 고속 외부 클럭 사용 시 128 분주
  - 512Hz 외부 출력으로 캘리브레이션 가능
- **2개의 알람 레지스터**: 특정 시간 및 날짜 필드에 대해 독립적으로 알람 설정 가능
- 주기적 인터럽트 생성을 위한 **16비트 자동 리로드 다운카운터**:
  - 주기 설정 범위: 120μs ~ 36시간
- **20비트 프리스케일러**로 1Hz 기반 생성 (32.768kHz 입력 기준)
- **보정 클럭 입력(50/60Hz)** 지원: 정밀한 캘린더 기능 구현 가능

---

### 💾 Backup SRAM

- 용량: **4KB**
- EEPROM과 유사한 비휘발성 저장 영역
- **VBAT 또는 Standby 모드**에서 데이터 유지 가능
- 기본적으로 비활성화되어 전력 소비 절감 → 소프트웨어로 활성화 가능

---

### 📚 Backup Registers

- 총 **20개**, 각각 **32비트**
- 최대 **80바이트** 사용자 데이터를 보존
- 시스템 리셋, 전원 리셋, Standby 복귀 후에도 내용 유지
- `VDD` 전원이 꺼진 상태에서도 백업 전원이 있으면 데이터 유지

📘 **참고**: Low-power mode 동작 시 해당 영역은 전력 최적화를 위해 특별하게 관리됩니다. 자세한 내용은 `Section 3.18: Low-power modes` 참고.
